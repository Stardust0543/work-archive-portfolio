# Work Archive

저장된 이력서(2026.08.21)만을 근거로 만든 반응형 경영관리 포트폴리오입니다.

- Profile / About / Skills / Career / Projects / Contact
- 프로젝트 상세 대화상자, 키보드 탐색, 스크롤 애니메이션 및 동작 줄이기 설정 지원
- 개인정보를 제외한 3쪽 PDF 다운로드
- 연락처를 공개하지 않는 문의 초안 작성·복사
- 외부 폰트·분석 서비스 없이 로컬 자산 사용

## 실행

빌드 과정이나 npm 패키지가 필요하지 않습니다.

```sh
python3 -m http.server 8080 --directory dist
```

PDF를 다시 생성할 때는 Python의 `reportlab` 패키지와 동봉된 OFL 폰트를 사용합니다.

```sh
python3 scripts/generate_pdf.py
```

## 개인정보와 호스팅

원본 이력서는 저장소에 포함하지 않습니다. 이름, 사진, 생년, 주소, 전화번호, 이메일 및 구직인증번호는 소스와 PDF에서 제외했습니다. 출판사명은 원본과 동일하게 비공개로 유지했습니다. 연락처나 개인정보를 다시 표시하는 기능은 없습니다. 문의는 전송되지 않고 브라우저에서 복사만 합니다.

Sites 호스팅은 소유자만 볼 수 있는 비공개 모드입니다. `noindex`만으로 접근이 제한되는 것은 아니며, 실제 접근 제한은 호스팅 서비스가 처리합니다. 공개 전환이나 GitHub Pages 활성화는 소유자의 명시적 승인 전에는 하지 않습니다.

직장명과 경력은 이력서에 기재된 전문 경력 정보입니다. 프로젝트의 수치 성과나 세부 일정을 추가로 추정하지 않았습니다.
